# NLP Project Evaluation (Vizlearning)

## ตารางเกณฑ์การประเมิน

| เกณฑ์การประเมิน | ดีเยี่ยม (4) | ดี (3) | พอใช้ (2) | ต้องปรับปรุง (1) | คะแนน |
|---|---|---|---|---|---|
| 1. ความเข้าใจในปัญหาและการรวบรวมข้อมูล | นิยามปัญหาชัดเจน อธิบายที่มาของ Dataset และขั้นตอนการทำ Pre-processing ได้อย่างครบถ้วน | นิยามปัญหาชัดเจน อธิบายข้อมูลและการทำ Pre-processing ได้ส่วนใหญ่แต่ขาดรายละเอียดบางจุด | นิยามปัญหาได้ แต่ขาดความชัดเจนในเรื่องลักษณะของข้อมูลหรือการเตรียมข้อมูล | ไม่สามารถอธิบายปัญหาหรือที่มาของข้อมูลได้ชัดเจน |  |
| 2. เทคนิคและการเลือกใช้โมเดล | เลือกใช้ Model/Architecture ได้เหมาะสมกับปัญหา และอธิบายเหตุผลทางเทคนิคได้ลึกซึ้ง | เลือกใช้โมเดลได้เหมาะสม แต่อธิบายเหตุผลในการเลือกหรือการปรับจูน (Hyperparameter) ได้ไม่ชัดเจนนัก | เลือกใช้โมเดลตามตัวอย่างทั่วไป ไม่ได้วิเคราะห์ความเหมาะสมกับลักษณะของข้อความ | เลือกใช้โมเดลไม่เหมาะสมกับงาน NLP ที่ได้รับ |  |
| 3. การวัดผลและการวิเคราะห์ (Evaluation) | ใช้ Metrics ที่ถูกต้อง (F1-score, BLEU, Perplexity ฯลฯ) มีการวิเคราะห์ Error Analysis ว่าทำไมโมเดลถึงทายผิด | มีการวัดผลที่ถูกต้อง แต่การวิเคราะห์ผลลัพธ์ยังไม่ลึกซึ้ง หรือขาด Error Analysis | วัดผลโดยใช้ Accuracy เพียงอย่างเดียว โดยไม่คำนึงถึงวัตถุประสงค์การวัดหรือ ใช้ Metricsไม่ถูกต้อง | ไม่มีการวัดผลที่เป็นรูปธรรม หรือวัดผลผิดวิธี |  |
| 4. ข้อจำกัดและความพร้อมใช้งานจริง | ระบุข้อจำกัดของโมเดล (Model Limitation) ชัดเจน มีแนวคิดการ Deployment และการจัดการกับ Data ในอนาคต | ระบุข้อจำกัดได้บางส่วน มีแนวคิดการนำไปใช้งาน แต่ยังขาดรายละเอียดเรื่องความเร็วหรือทรัพยากรที่ใช้ | พูดถึงการนำไปใช้งานเพียงกว้างๆ ไม่มีการระบุข้อจำกัดของระบบที่พัฒนาขึ้น | ไม่คำนึงถึงข้อจำกัดหรือการนำไปใช้งานจริง เน้นเพียงผลลัพธ์ในชุดทดสอบ |  |
| 5. ทักษะการนำเสนอและสื่อความหมาย | เล่าเรื่องเป็นระบบ สไลด์สวยงาม สื่อสารแนวคิดยากๆ ให้เข้าใจง่าย ภายในเวลาที่กำหนด | นำเสนอได้ดี สไลด์อ่านง่าย แต่ไม่สามารถสื่อสารแนวคิดให้เข้าใจได้ | อ่านตามสไลด์เป็นส่วนใหญ่ สไลด์มีตัวอักษรแน่นเกินไป หรือจัดการเวลาไม่ดี | ไม่สามารถเรียบเรียงเนื้อหาได้ นำเสนอสับสน |  |
| 6. การตอบคำถามและปฏิภาณไหวพริบ | ตอบคำถามเชิงเทคนิคได้อย่างถูกต้อง มั่นใจ และแสดงให้เห็นถึงความเข้าใจในตัวโมเดลอย่างแท้จริง | ตอบคำถามได้ส่วนใหญ่ แต่อาจมีบางประเด็นที่ยังตอบได้ไม่เคลียร์ | ตอบคำถามได้เพียงกว้างๆ ไม่สามารถลงรายละเอียดเชิงเทคนิคได้ | ไม่สามารถตอบคำถามเกี่ยวกับโครงงานของตนเองได้ |  |
| 7. ความคิดสร้างสรรค์และนวัตกรรม (Wow Factor) | มีทำเทคนิคใหม่หรือการแก้ปัญหาได้อย่างชาญฉลาด | โครงงานมีความน่าสนใจ มีความพยายามที่จะทำสิ่งใหม่ๆ นอกเหนือจากในบทเรียน | เป็นโครงงานตามโจทย์มาตรฐานทั่วไป (เช่น Sentiment Analysis พื้นฐาน) | เป็นการคัดลอกโปรเจกต์จาก Tutorial ทั่วไปโดยไม่มีการดัดแปลง |  |
